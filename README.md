# 👗 StyleMate - Fashion Chatbot

✨ **StyleMate** is an AI-powered fashion advisor built with Streamlit that delivers stylish outfit ideas, color matching tips, wardrobe advice, and fashion guidance—all in real time.

---

## 🚀 Features

- 🧠 AI-driven fashion stylist using powerful LLMs (via OpenRouter API)  
- 🗣️ Chat-based interface to get outfit suggestions, seasonal style tips, and more  
- 🎨 Tailored advice for occasions, body types, color palettes, and trends  
- 🔐 Secure API key input via sidebar (user-controlled)  
- 🎯 Supports multiple models and creativity levels  
- 🧼 One-click clear chat function  
- 💄 Aesthetic, responsive UI with a fashion-inspired background  

---

## 🛠️ Tech Stack

- **Frontend**: Streamlit (with custom CSS for chat layout and style)  
- **Backend**: OpenRouter API (chat completion using LLMs)  
- **Languages**: Python  

---

## 🔧 Setup Instructions

1. Clone the repository:
    ```bash
    git clone https://github.com/your-repo/stylemate-fashion-chatbot.git
    cd stylemate-fashion-chatbot
    ```

2. Install required packages:
    ```bash
    pip install -r requirements.txt
    ```

3. Launch the chatbot:
    ```bash
    streamlit run app.py
    ```

4. Add your OpenRouter API key in the sidebar  
   👉 [Get your API key here](https://openrouter.ai/keys)

---

## 🧠 How It Works

- The chatbot uses a **strict system prompt** to stay focused on fashion, clothing, and styling.
- You can ask about:
  - 👚 What to wear for a specific occasion  
  - 🎨 What colors go well together  
  - 💃 Outfits that flatter your body type  
  - 🧥 Seasonal fashion essentials and trends  
- Fun, friendly, and always fashionable responses in plain text only!

---

## 📌 Note

This chatbot **only answers fashion-related queries**. Ask it anything outside of that, and it'll kindly redirect you back to the runway. 💃
